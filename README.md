# Stoneless
Covers the screen at set intervals until you do a timed drink-water step for both windows and linux(hyprland)


## Tech Stack Used

python , tkinter for GUI, and psutil (for the hang matchdog)

## Features
- suitable for hyprland 
hyprland.conf modifications in docs/HYPRLAND.md

- works on both windows and linux

- helps you drink more water (8 glasses a day or wtv the standard is)

- keeps you healthy

## Limits

- it cannot check that you really drank ,the timed step only adds friction

- it is an overlay , not an OS lock, ctrl+alt+del still wroks on windows and compositor shortcut still works
